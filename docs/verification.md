# Проверки версии 0.1.0

15 ноября 2026 года, Node.js 26.13.0.

- `npm run build` — ESM, classic IIFE, типы и самостоятельное демо собираются успешно.
- `npm test` — 23 проверки проходят. Проверены SSR-импорт, независимые экземпляры, очистка ресурсов, пауза, reduced motion, видимость вкладки и контейнера, null canvas, custom elements, таймер, безопасный текст открытки и взаимодействия демо.
- DOM-проверки выполняются в happy-dom с имитацией Canvas, RAF, media queries и observers. Они проверяют состояние и обработчики, а не реальное рисование или плавность анимации.
- Проверены генерируемые вставки: `type="button"`, доступная пауза, локальная полночь таймера, feedback копирования внутри модального диалога и восстановление после BFCache.
- `git diff --check` и синтаксическая проверка JavaScript проходят.
- Минимальная сборка: 19 312 байт, 7 268 байт в gzip. Бюджет относится к библиотеке, без SVG и кода демо.
- Демо опубликовано через Sites. Браузерная автоматизация в этом чате недоступна, поэтому визуальная проверка desktop/mobile, настоящий hit testing и проверки в Chromium/Firefox/WebKit **не выполнены**. Адаптивные стили подготовлены, но синтетические тесты не доказывают их визуальное качество.

Для повторения: `npm ci`, `npm run build`, `npm test`, затем `npm run dev`. Откройте напечатанный локальный URL и проверьте 320/390/768/1440 px, клавиатуру и системное уменьшение движения.
